SYNTHIA - Training Project

🚀 About
This is a training project created for my **personal portfolio**. 
The main goal was to practice modern web layout techniques, UI styling, and basic JavaScript integration.

🛠 Tech Stack
* HTML5 / SCSS — semantic layout and custom styling.
* JavaScript — custom form validation logic.
* Particles.js — implemented a dynamic background using this library (customized speed and density to fit the design).

💡 Key Features & Learning
* Library Integration: Successfully integrated and configured external JS libraries.
* Modern UI: Worked with transparencies, blurs, and layered backgrounds (`z-index`).
* Form Logic: Created a functional script to validate user input.
* Interactive Elements: Implemented carousels and hover effects.


Note: This project is a work in progress as I continue to improve my frontend development skills.
