SYNTHIA — Training Project

🚀 About
A training project created for a personal portfolio. The main goal was to improve UI development skills, integrate JavaScript, and build a responsive version of the site optimized for phones, tablets, and laptops.

💡 Key Features & UX:
1.Custom UX: A completely original concept, structure, and interface interaction logic, designed entirely from scratch.
2.Responsiveness: Built with a fluid layout that seamlessly adapts to mobile versions, tablets, and laptop screens.
3.Advanced CSS Elements: All core interactivity is implemented natively using stylesheets to maintain high performance without overloading the page:

  - 3D card flips (180-degree rotation on hover).
  - Interactive carousel for content browsing.
  - Linear gradients (left-to-right) and a frosted glass effect.
  - A continuous moving background ticker (text slider).

🛠 Tech Stack
- HTML5 / SCSS — semantic layout, CSS variables, fluid responsive formulas, layer depth management (z-index), and complete animation logic.
- JavaScript — utilized strictly for integrating and configuring the external Particles.js library (customized speed and density to align with the overall design).
